# CELL WORLD 수정 항목

## 1. AI NPC API 사용량 제한

### 대상 파일

- `src/app/api/npc/chat/route.ts`
- 필요 시 rate limit 유틸리티 파일

### 수정 내용

- IP 또는 익명 세션 기준 호출 제한을 적용합니다.
- 제한을 초과한 요청에는 `429 Too Many Requests`를 반환합니다.
- 요청 본문 크기를 제한합니다.
- `npcId`와 `questStatus`를 허용된 값으로 제한합니다.
- OpenAI 호출 실패 시 현재의 로컬 NPC 폴백을 유지합니다.
- NPC 기억에 사용자 질문 전체를 저장하지 않고 퀘스트 단계와 최근 주제 등 구조화된 값만 저장합니다.
- `OPENAI_API_KEY`는 서버 환경 변수에서만 사용합니다.

## 2. Keeper 경비 시야 벽 판정

### 대상 파일

- `src/game/scenes/CellOfficeKeeperScene.ts`

### 수정 내용

- 경비와 플레이어 사이의 벽 및 큰 가구를 시야 차단 대상으로 처리합니다.
- 거리와 각도 조건을 만족하더라도 차단물이 있으면 감지하지 않도록 변경합니다.
- 시야 콘의 표시 범위와 실제 감지 범위를 일치시킵니다.
- 열린 복도에서는 기존처럼 정상적으로 감지되도록 유지합니다.
- 보안 패스, 시간 10초 차감, 시작 위치 복귀 로직은 유지합니다.

## 3. RPG 사망 및 재시작 처리

### 대상 파일

- `src/game/scenes/CellWorldRpgScene.ts`
- `src/stores/gameStore.ts`
- `src/components/GameHud.tsx`
- 필요 시 RPG 사망 패널 컴포넌트

### 수정 내용

- HP가 0이 되면 플레이어 이동, 공격, 상호작용을 중지합니다.
- Zustand 스토어에 RPG 실행 상태 또는 사망 상태를 추가합니다.
- 사망 상태를 HUD 또는 결과 패널에 표시합니다.
- 사망 후 HP와 플레이어 위치를 초기화하여 다시 시작할 수 있게 합니다.
- 일반 사망 후에는 퀘스트 진행도와 골드를 유지합니다.
- `RESTART SHEET`를 선택하면 RPG 전체 진행도를 초기화합니다.
- 새로고침 후 HP가 0인 상태에서도 복구할 수 있게 합니다.

## 4. 게임 전환 로딩 및 오류 상태

### 대상 파일

- `src/components/game/GameCanvas.tsx`

### 수정 내용

- 게임 ID 또는 `sessionRevision`이 변경될 때 `isLoading`을 다시 `true`로 설정합니다.
- Phaser 인스턴스 생성이 완료되면 로딩 상태를 해제합니다.
- 동적 import 또는 Phaser 생성 실패를 처리하는 오류 상태를 추가합니다.
- 초기화 실패 시 빈 캔버스 대신 오류 메시지와 재시도 UI를 표시합니다.
- 게임 전환 시 기존 Phaser 인스턴스가 항상 제거되도록 유지합니다.

## 8. 자동 테스트 추가

### 대상

- AI NPC Route Handler
- Zustand 게임 상태
- Keeper 시야 판정
- RPG 사망 처리
- Defence 보스 생성 조건

### 수정 내용

- 잘못된 NPC 요청이 `400`을 반환하는 테스트를 추가합니다.
- 호출 제한 초과 시 `429`를 반환하는 테스트를 추가합니다.
- OpenAI 키가 없거나 요청이 실패했을 때 폴백 응답을 반환하는지 확인합니다.
- RPG HP가 0 미만으로 내려가지 않고 사망 상태로 전환되는지 확인합니다.
- Keeper가 벽 뒤의 플레이어를 감지하지 않는지 확인합니다.
- Keeper가 열린 시야의 플레이어는 감지하는지 확인합니다.
- 문서 3개 회수 후 출구가 활성화되는지 확인합니다.
- Defence에서 12킬 이후 보스가 생성되는지 확인합니다.
