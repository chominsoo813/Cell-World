# Cell Office: #REF! 화면별 이미지 에셋 매트릭스

## 1. 제작 원칙

- `public/assets/pixel-art/office-ref`만 Cell Office 전용 런타임 이미지 패키지로 사용한다.
- `office-defence` 이미지와 소스는 참조하거나 재사용하지 않는다.
- 기존 `office-ref`의 검정 윤곽, 제한된 사무실 색상, 정면·후면·좌우 4방향 픽셀 캐릭터 스타일을 유지한다.
- 패널, 버튼, 셀 격자, 연결선, 시야 원뿔, 게이지, 타이머와 미니맵은 해상도와 상태 변화에 맞춰 코드로 그린다.
- 캐릭터, 환경 오브젝트, Session 대표 이미지와 의미를 가진 픽셀 아이콘만 PNG로 제작한다.
- 개별 PNG와 원본 시트를 함께 보관하고 `manifest.json`에 용도와 상태를 기록한다.
- UI 아이콘은 정사각형 안전 영역, 캐릭터는 공통 발 기준점, 환경 오브젝트는 공통 바닥 기준선을 사용한다.

## 5. 검수 기준

- 투명 모서리와 알파 채널이 정상이며 키 색상 테두리가 남지 않아야 한다.
- 기존 캐릭터와 함께 놓았을 때 윤곽선 굵기, 광원 방향과 명암 단계가 이질적이지 않아야 한다.
- 아이콘은 32px 표시에서도 실루엣과 의미가 구분되어야 한다.
- 좌우 방향 캐릭터는 장비, 얼굴과 옷 색이 일치해야 한다.
- 모든 캐릭터의 발 기준점과 장치의 바닥 기준선이 동일해야 한다.
- 문자가 필요한 오류 아이콘 외에는 이미지 안에 작은 텍스트를 넣지 않는다.
- 색약 팔레트에서도 아이콘 실루엣과 패턴만으로 상태를 구분할 수 있어야 한다.
