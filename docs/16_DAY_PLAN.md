# CELL WORLD 16일 개발 실행안

## 목표

16일 안에 링크 접속 즉시 플레이할 수 있는 해커톤 사전 과제 MVP를 완성한다.

- 스프레드시트로 위장한 게임이라는 콘셉트를 5초 안에 전달한다.
- RPG는 의뢰 수락부터 보상까지 하나의 완결된 퀘스트를 제공한다.
- Keeper와 Defence는 각각 3~5분 안에 이해되는 플레이 루프를 제공한다.
- AI NPC는 현재 진행 상태를 이해해 대화와 힌트를 제공한다.
- AI 장애나 네트워크 지연이 게임을 중단시키지 않는다.

## AI 서버 규칙

```text
브라우저
  → POST /api/npc/chat
  → Zod 입력 검증
  → OpenAI Responses API
  → 앱에서 허용한 action과 기억 요약 반환
  → 게임 코드가 실제 상태 변경
```

AI는 골드·아이템·클리어 상태를 직접 수정하지 않는다. `offer_quest`, `give_hint`, `suggest_item`, `complete_quest`처럼 제한된 행동만 제안하며, 실제 적용 여부는 Zustand 게임 로직이 결정한다.

## 제출 직전 기준

- 처음 접속 후 10초 안에 게임 선택이 가능하다.
- 세 시트 전환 시 Phaser 인스턴스가 중복 생성되지 않는다.
- API 키가 클라이언트 코드나 빌드 결과에 포함되지 않는다.
- AI가 실패해도 1초 내 폴백 안내가 표시된다.
- 1366×768 화면에서 게임·HUD·시트 탭을 동시에 확인할 수 있다.
- 데모 영상은 홈 → RPG AI 대화 → Keeper → Defence 순서로 구성한다.
