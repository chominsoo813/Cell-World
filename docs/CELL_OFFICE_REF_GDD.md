# Cell Office: #REF! 게임 기획서

> 문서 상태: 콘셉트 및 첫 번째 세션 설계안
> 대상 프로젝트: CELL WORLD
> 장르: 실시간 스프레드시트 편집 퍼즐 · 잠입 · 세션형 어드벤처

## 1. 게임 한 줄 소개

퇴근 직전 손상된 회사 파일에 갇힌 직원이 `HIDE`, `COPY`, `SORT`, `IF`, `UNDO` 같은 스프레드시트 기능으로 사무실의 규칙을 편집해 탈출하는 게임이다.

플레이어는 적을 직접 쓰러뜨리기보다 적과 공간이 존재하는 셀의 규칙을 고친다.

## 2. 기획 의도

기존 `Cell Office Keeper`는 제한 시간 안에 업무 파일 세 개를 회수하고 경비와 CCTV를 피해 탈출하는 구조다. 기본적인 잠입 게임으로서는 동작하지만, 다른 잠입 게임과 구별되는 핵심 경험이 부족하다.

새 설계의 목표는 CELL WORLD의 스프레드시트 외형을 게임 규칙으로 확장하는 것이다. 리본 메뉴, 수식 입력창, 행과 열, 필터와 오류가 장식이 아니라 플레이어의 도구가 되어야 한다.

### 핵심 판타지

> 회사 시스템의 허점을 찾아 현실을 해킹하고 퇴근한다.

### 디자인 원칙

1. 모든 주요 퍼즐은 스프레드시트 기능으로 해결할 수 있어야 한다.
2. 하나의 문제에는 가능한 한 두 가지 이상의 해결법을 제공한다.
3. 명령은 이해하기 쉽고, 명령의 조합에서 깊이가 생겨야 한다.
4. 회사 생활의 부조리와 스프레드시트 용어를 유머와 서사에 활용한다.
5. 실패는 긴장감을 주되 긴 플레이 시간을 통째로 지우지 않는다.

## 3. 제품 구조

메인 캠페인은 6개 세션, 총 30개 스테이지로 구성한다.

| 구분 | 구성 |
|---|---|
| 세션 수 | 6개 |
| 세션당 구성 | 일반 시트 3개 + 특수 시트 1개 + FINAL SHEET 1개 |
| 세션 플레이 시간 | 약 20~30분 |
| 전체 메인 스테이지 | 30개 |
| 캠페인 이후 | OVERTIME MODE 및 일일 파일 |

세션이 끝나면 진행 상황을 저장한다. 세션 내부에서는 선택한 함수 강화, 계산 자원, 문서 손상도가 누적된다.

## 4. 핵심 플레이 루프

1. 출근 준비 화면에서 사용할 함수 세트를 선택한다.
2. 이동 모드에서 사무실을 탐색하고 경비와 CCTV를 관찰한다.
3. 편집 모드에서 행, 열, 사물 또는 인물을 선택한다.
4. 수식을 실행해 공간이나 규칙을 변경한다.
5. 변경된 상황을 이용해 목표를 달성한다.
6. 시트 완료 후 함수 강화 또는 매크로를 선택한다.
7. FINAL SHEET의 종합 규칙 퍼즐을 해결하고 영구 보상을 획득한다.

## 5. 조작 구조

### 화면 내비게이션 계층

CELL WORLD 전체와 Office 내부 진행은 서로 다른 위치와 표현을 사용한다.

- 화면 맨 아래의 시트 탭은 `Game Select`, `RPG Map`, `Office`, `Defence`처럼 게임 전체를 전환하는 전역 내비게이션으로만 사용한다.
- Office 세션의 `Sheet 1/5` 진행도는 오른쪽 HUD의 세션 패널에 표시한다.
- 일반 플레이 중에는 현재 스테이지 이름과 진행도만 보여주고, 다음 스테이지 선택과 강화 보상은 시트 완료 화면에서 처리한다.
- Office 내부 스테이지를 하단에 중첩된 시트 탭으로 다시 만들지 않는다.

이 구분으로 하단 시트 탭의 기존 의미를 보존하고, 플레이어가 게임 전환과 세션 진행을 혼동하지 않게 한다.

### 논리 그리드

- 모든 맵은 100×100 게임 단위의 정사각형 셀을 사용한다.
- 첫 프로토타입은 14열×10행의 `A1:N10` 맵이다.
- 플레이어 이동은 자유롭게 유지하고 편집과 함수 판정만 셀 단위로 처리한다.
- 캐릭터 좌표는 발 위치, 사물 좌표는 명시적인 기준 셀을 사용한다.
- 벽은 셀 단위 조각으로 구성해 HIDE와 공간 접힘을 일관되게 처리한다.

### 이동 모드

| 입력 | 동작 |
|---|---|
| `WASD` 또는 방향키 | 이동 |
| `Space` | 편집 모드 진입 |
| `E` | 가까운 장치 또는 인물 조사 |
| `Esc` | 일시 정지 또는 메뉴 닫기 |

- 걷기는 초당 1.8셀, Shift 달리기는 초당 3셀이며 스태미나와 웅크리기는 없다.
- BULKY 물건을 들면 달릴 수 없고 초당 1.35셀로 감소한다.
- 가구는 0.6초에 한 셀씩 밀며 WHEELED 개체만 당길 수 있다.
- 평상시 달리기는 경비를 부르지 않고 경보 2단계부터 발소리 조사를 발생시킨다.

### 편집 모드

편집 모드에 진입하면 시간이 완전히 멈추지 않고 20% 속도로 흐른다. 화면에는 스프레드시트 좌표와 선택 가능한 범위가 표시된다.

- 경비, CCTV, 장치, 제한 시간, 함수 지속시간도 동일하게 20% 속도로 흐른다.
- 편집 중 플레이어는 이동할 수 없지만 탐지 판정은 계속된다.
- 함수 실행에 성공하면 자동으로 이동 모드로 복귀한다.
- 접근성 옵션으로 불이익 없는 완전 정지 모드를 제공한다.

일반 함수와 오류 함수의 기본 EDIT RANGE는 플레이어 중심 반경 4셀의 9×9 영역이다. 벽과 닫힌 문은 데이터 편집을 막지 않지만 READ_ONLY와 LOCKED는 막는다. HIDE는 범위 안의 행·열 머리글을 선택하면 전체 선에 적용하고, UNDO·MACRO와 연결된 DISPATCH TERMINAL 또는 LINKED RANGE만 원격 예외를 가진다.

| 입력 | 동작 |
|---|---|
| 방향키 또는 마우스 | 행·열·대상 선택 |
| 숫자키 | 함수 슬롯 선택 |
| `Enter` | 수식 실행 |
| `Esc` 또는 `Space` | 편집 취소 |

플레이어가 실제 수식을 전부 타이핑하도록 강요하지 않는다. 함수와 대상을 선택하면 수식 입력창에 완성된 명령이 출력되는 방식으로 구성한다.

- 진입 즉시 플레이어가 서 있는 셀을 기본 선택한다.
- 방향키로 셀을 이동하고 `Tab`으로 셀, 행, 열, 개체 선택을 순환한다.
- `Q/E`로 같은 셀의 개체를 순환하고 숫자키 `1~4`로 함수 슬롯을 선택한다.
- 마우스로 셀, 행 머리글, 열 머리글, 개체를 직접 선택할 수도 있다.
- 실행 전 결과, CALC 비용, 지속시간을 반투명 미리보기로 제공한다.

```text
=HIDE(ROW_7)
=COPY(KEYCARD_B4)
=PASTE(INVENTORY_1)
```

### 플레이 HUD와 편집 화면

이동 중에는 잠입 공간을 가리지 않는 최소 HUD만 사용하고, 홈 화면 하단의 전역 게임 선택 시트는 플레이에 들어오면 렌더링하지 않는다.

- 왼쪽 위: 현재 파일, Session·Sheet 진행도와 접을 수 있는 목표
- 위쪽 중앙: 관리자 행동과 긴급 이벤트가 있을 때만 나타나는 타이머
- 오른쪽 위: 경보 단계와 `COMPLIANT` 또는 현재 규정 위반 사유
- 왼쪽 아래: 상황별 상호작용과 HANDS, BADGE, CLIPBOARD
- 아래쪽 중앙: 함수 `1~4`, 오류 `5`, UNDO `Z`, MACRO `M`, 현재 CALC
- 오른쪽 아래: 자동 복구와, Session 5 이후 또는 손상 발생 시 손상도·이상 현상·보류 손상
- 관찰자별 탐지 게이지는 해당 경비와 CCTV 머리 위에 표시하고, 파일 패치는 평소 작은 스택으로 접어 둔다.

`Space` 편집 모드에서는 플레이어 중심 9×9 영역에 반투명 행·열 머리글과 격자를 세계 위로 펼친다. 왼쪽에는 대상 속성 검사, 오른쪽에는 CALC·손상도·지속시간·경보·최종 결과의 실행 미리보기, 아래에는 함수와 완성 수식을 배치한다. 자동 채우기나 연쇄 변경은 별도 설명창보다 고스트 셀과 연결선으로 보여준다. `WORLD 20%`와 흐르는 타이머를 위에 유지하며, 유효하지 않은 대상은 빨간 윤곽선과 실패 이유를 표시하고 실행을 막는다.

편집 중 방향키 또는 WASD로 셀을 이동하고 `Shift`로 범위를 확장한다. `1~5`, `Z`, `M`으로 기능을 선택하고 `Enter`로 실행하며, `Space` 또는 `Esc`는 비용 없이 취소한다. 색상에는 아이콘과 패턴을 병용하고 중요 타이머에는 숫자를 표시한다.

### 셀 선택과 함수 실행 피드백

함수 실행은 `선택 → 실행 예고 → 결과`의 세 단계로 표현한다. 선택한 셀에는 좌표와 청록색 테두리, 영향 범위에는 점선, 영향을 받는 인물과 장치에는 함수 아이콘을 표시한다. 유효하지 않은 대상은 빨간 윤곽선과 구체적인 실패 이유를 표시한다.

`Enter`로 확정하면 약 0.4초 동안 완성된 수식과 계산선을 영향 순서대로 보여준다. 손상 또는 경보가 예정되면 적용 직전에 위험 색과 아이콘으로 경고한다. 확정 전에는 취소할 수 있지만 이 실행 예고가 시작된 뒤에는 결과를 바꿀 수 없다.

정상 결과는 이전 값과 새 값의 청록색 갱신, 규정 우회는 `COMPLIANT`, 보안 반응은 원인에서 관찰자나 장치로 이어지는 붉은 계산선으로 표현한다. 오류 함수에는 짧고 판독 가능한 글리치와 오류명을 사용한다. 다중 변경은 실제 처리 순서대로 연쇄 적용하며 마지막에 행동, CALC 변화와 경보 결과를 한 줄로 요약한다.

이미 본 연출은 클릭 또는 `Enter`로 단축할 수 있고 설정에서 속도, 글리치, 흔들림과 섬광 강도를 조절한다. 단축은 시각 연출만 줄이며 게임 판정 순서는 유지한다.

### 경보와 실패 화면

경보 상승은 플레이를 막는 팝업 대신 화면 가장자리의 짧은 경보 효과, `ALERT 1 → 2`, 발생 원인과 새 단계의 행동 한 줄로 전달한다. 원인 셀과 반응한 경비·CCTV·장치를 붉은 계산선으로 연결하며 조작권과 카메라는 유지한다.

시트에 실패하면 세계를 정지하고 마지막 장면 위에 `WORKBOOK RECOVERY`를 연다. 실패 종류, 플레이어 행동에서 최종 실패까지의 핵심 인과관계, 자동 복구 소비 전후 값을 보여주고 `규칙 다시 보기`, `Sheet 재시작`, `세션 종료`를 제공한다. 규칙 보기에서는 방금 관련된 항목을 우선 강조하며 재시작은 시트 시작 상태로 되감긴다. 자동 복구가 0이면 재시작 대신 세션 결과와 보존되는 영구 진행을 안내한다.

### Sheet 완료 결과

완료 후에는 전체 화면 `SHEET_RECAP.xlsx`에서 Session·Sheet 진행도, 필수·선택 목표의 감사 도장, 함수 실행 순서, CALC 사용량, 최고 경보 단계, 소요 시간과 다음 시트로 이어지는 파일 상태를 정리한다. S/A/B 같은 종합 등급이나 보상 배율은 두지 않고 기록은 풀이를 이해하고 비교하는 용도로만 사용한다.

이미 획득한 선택 목표와 새로 획득한 목표를 구분하고, 미달성 목표는 정답 대신 재도전 힌트를 보여준다. 핵심 행동만 맵에서 재생하는 `풀이 다시 보기`를 제공한다. Sheet 1~4의 다음 동선은 `파일 패치 선택`, FINAL은 `Session 결산`, HIDDEN은 독립 보상 확인 뒤 이전 메뉴 복귀로 연결한다. 완료 상태는 결과 화면 전에 저장하고 재도전은 이후 시트 선택 메뉴에서 시작한다.

### Session 결산

FINAL SHEET 완료 뒤에는 `SESSION_CLOSE.xlsx`에서 이번 세션 기록, 영구 저장되는 보상과 종료되는 임시 상태를 세 영역으로 분리한다. 완료 시트, 감사 도장과 플레이 기록을 왼쪽에, 새 함수·시스템·STORY FILE·HIDDEN 진행도를 중앙에, 파일 패치·손상도·이상 현상·자동 복구를 오른쪽에 표시한다.

파일 패치는 `ARCHIVED` 처리하고 손상도와 이상 현상은 워크북을 닫으며 0으로 초기화한다. 자동 복구는 이월되지 않음을 보여준다. 영구 보상은 선택 없이 모두 지급하며 새 기능의 짧은 사용 예시와 다음 Session의 제목·핵심 규칙 하나를 제공한다. Session 6은 결말 결과를 먼저 보여준 뒤 같은 결산 구조로 연결한다.

### Sheet 브리핑과 함수 로드아웃

시작 직전 `SHEET_BRIEF.xlsx`는 목표·규정, 간략 미니맵, 함수 로드아웃의 세 영역으로 구성한다. 목표와 실패 조건, 사내 규정은 정확히 공개하되 미니맵에는 알려진 구역과 장치만 표시하고 순찰 해법, 숨은 통로와 미발견 장치는 감춘다. 실패 후에는 직전 원인과 관련 규칙을 상단에서 다시 확인할 수 있다.

로드아웃에는 일반 함수 `1~4`, 오류 슬롯 `5`, UNDO `Z`, MACRO `M`을 표시한다. 필수 함수는 이유와 함께 고정하고 자유 슬롯은 영구 해금 목록에서 교체한다. 파일 패치가 적용되는 슬롯에는 아이콘을 붙인다. 추천 정답 조합은 제공하지 않고 직전 로드아웃과 필수 슬롯 자동 배치만 지원한다. 튜토리얼은 전체 구성을 고정한다.

`PATCH_NOTES.xlsx`의 `다음 Sheet 열기`에서 파일 패치는 이미 확정되므로 브리핑에서는 바꿀 수 없다. 실제 시작 전에는 자원을 소비하지 않으며 실패·재시작 뒤에는 같은 시트 상태에서 로드아웃만 다시 구성할 수 있다.

### Session·Sheet 선택과 재도전

Office 탭의 `OFFICE_INDEX.xlsx`는 왼쪽 Session 1~6·OVERTIME 목록, 중앙 Sheet 1~4·FINAL 진행 경로, 오른쪽 목표·감사 도장·기록·해금 정보로 구성한다. 기존 하단 게임 시트는 전역 게임 전환용으로 유지하고 Office 내부 선택기는 그 위에 배치한다. HIDDEN SHEET는 감사 도장 12개 전까지 `???` 탭으로 보인다.

완료한 시트에서는 당시 조건으로 도장을 얻는 STORY VERSION과 현재 모든 해금으로 실험하는 RECALC VERSION을 선택한다. 재도전은 독립 복사본에서 실행해 진행 중인 Session의 손상도, 파일 패치, 이상 현상과 자동 복구를 변경하지 않으며 종료 후 현재 Story 체크포인트로 복귀한다. `계속하기`도 시트 중간이 아닌 시트 시작에서 시작한다. 최근 실패 원인과 관련 규칙을 함께 제공하고 현재 주 진행 버튼 하나만 강조한다.

### 일시정지·규칙 사전·힌트

`Esc`는 세계를 완전히 멈추고 `HELP_DESK.xlsx`를 연다. 현재 Sheet, 검색 가능한 규칙 사전, 함수 도움말, 힌트와 설정 탭을 제공한다. 마지막 장면은 유지하지만 자유 카메라 정찰은 허용하지 않는다. `F1`은 최근 발생하거나 포커스한 규칙 설명으로 바로 이동하며 아직 만나지 않은 정보는 `???`로 감춘다.

힌트는 목표와 공개 규칙 재설명, 확인할 구역·시스템 관계, 유용한 함수 조합 방향의 세 단계로 플레이어가 직접 연다. 정확한 셀과 실행 순서는 공개하지 않으며 사용해도 보상과 감사 도장을 줄이지 않고 개인 기록에만 남긴다.

Sheet 재시작에는 자동 복구 소비 전후 값을 직접 표시하고, Session 종료에는 사라질 임시 상태를 목록으로 제시한 뒤 확인받는다. 재도전 복사본과 HIDDEN SHEET에서는 본편 자동 복구가 소비되지 않음을 같은 위치에 표시한다.

### 접근성과 플레이 보조

`HELP_DESK.xlsx > 설정`에서 HUD 크기, 일반 폰트, 격자·시야 대비, 색약 팔레트, 흔들림·글리치·섬광·줌 감소와 숫자 타이머를 개별 설정한다. 대사·효과음 자막과 방향성 소리 캡션, 분리 음량, 전체 입력 재지정, 길게 누르기·토글과 커서 반복 속도를 지원한다.

플레이 보조로 편집 모드 속도 `20%/10%/정지`, 탐지 상승 `100%/75%/50%`, 행동 예고 `기본/1.5배/2배`, 특수 제한시간 `기본/1.5배/없음`, 자동 복구 소모 여부와 연출 속도를 제공한다. 설정은 언제든 바꿀 수 있고 콘텐츠, 함수 해금, 감사 도장과 외형 보상을 제한하지 않는다. 개인 기록에는 사용 설정만 남기며 경쟁 기록이 생길 경우에만 설정별로 분리한다.

### 첫 실행 튜토리얼

Session 1 직전의 짧은 안전 프롤로그에서 이동, 조사, 편집 모드, 대상 선택·미리보기와 HIDE 실행을 실제 출근 장면 안에서 차례로 익힌다. 경비는 체포하지 않으며 움직이는 사원과 시계로 편집 중 세계가 20% 속도로 흐름을 보여준다. 이 구간은 본편 Sheet 밖이므로 실패와 자동 복구를 사용하지 않는다.

안내는 한 번에 하나만 실제 대상 옆에 표시하고 입력 장치에 맞춰 표기를 바꾼다. 기능을 두 번 성공하면 기본 안내를 숨기고, 놓친 설명은 `F1`과 도움말에서 다시 볼 수 있다. 새 함수는 처음 필요한 순간에 나눠 설명한다. `안내 최소화`는 제공하지만 Story와 해금 과정은 생략하지 않으며 강제 퀴즈와 긴 설명 영상은 사용하지 않는다.

### 시각 언어

이동 중에는 희미한 셀 경계를 가진 픽셀 사무실로 보이고 `Space` 편집 모드에서만 EDIT RANGE의 행·열과 좌표가 선명해진다. 포커스한 대상만 외곽선을 표시한다. 선택은 청록 실선, 준수는 초록 체크, 예정 변화는 노랑 점선, ALERT 2는 주황 삼각형, 실패·ALERT 3은 빨강 이중선, 오류·손상은 보라색 깨진 셀, LOCKED·READ_ONLY는 회색 자물쇠와 빗금으로 통일한다.

HIDE는 가로지른 눈, COPY/PASTE는 겹친 셀, SORT는 교차 화살표, FILTER는 깔때기, IF는 분기 다이아몬드, UNDO는 역방향 화살표, MACRO는 셀 체인, 오류는 문자가 든 깨진 셀 아이콘을 사용한다. FORMULA·SYSTEM·RISK·REPAIR 패치는 색과 함께 서로 다른 탭 실루엣을 가진다. 경보는 화면 전체 필터 대신 조명과 보안 장치·경비의 국소 상태를 변화시켜 셀 판독성을 보존한다.

### 사운드 언어

프린터, 복사기, 키보드, 내선 전화와 사무실 방송을 전자적으로 변형해 효과음의 정체성을 만든다. HIDE는 접힘, COPY는 스캔, PASTE는 도장과 배출, SORT는 키 재배열, FILTER는 흡입과 클릭, IF는 질문과 분기 종결, UNDO는 역재생, MACRO는 함수 리듬, 오류 함수는 종류별 디지털 파열음으로 구분한다.

탐지음은 관찰자 방향에서 들리고 게이지가 오를수록 빨라진다. ALERT 1은 단일 알림, ALERT 2는 내선 전화, ALERT 3은 낮은 비상 방송을 사용하며 관리자 행동은 실행 2초 전 세 번 카운트한다. 편집 모드에서는 배경과 환경음만 낮추고 위험음은 유지한다. 손상도 25/50/75에서 음악의 손상 음층을 추가한다. 반복음은 작은 변주를 가지며 모든 핵심 소리에는 캡션과 시각 신호를 병용한다.

### 독자 제작 오디오 에셋

Office Defencer나 외부 게임 에셋을 재사용하지 않고 사무기기 질감과 전자음 합성으로 약 30개의 1차 팩을 제작한다. 함수음 약 11개, 오류 함수 4개, 탐지·경보·관리자 예고 약 7개, UI 약 6개와 환경·음악 레이어 루프를 포함한다.

원본은 `48 kHz / 24-bit WAV`, 게임용은 `OGG`로 관리한다. 공간 방향이 필요한 소리는 모노, HUD·메뉴·전체 경보와 환경 루프는 용도에 따라 스테레오로 만든다. 반복 효과에는 변형을 제공하고 파일명, 조건, 길이, 루프 지점과 음량을 매니페스트에 기록한다. 기획 확정 뒤 대표 샘플 팩을 먼저 플레이 테스트하고 전체 팩으로 확장하며 Office 전용 오디오 폴더에 보관한다.

### 반응형 배경음악

Session 1은 전자 피아노와 프린터, Session 2는 복사기·컨베이어 오피스 펑크, Session 3은 시계 기반 미니멀 잠입, Session 4는 테이프·역재생 기억 테마, Session 5는 누적 글리치, Session 6은 앞선 음형의 결합을 중심으로 한다. 각 Session은 2~3분 루프와 같은 주제의 FINAL 변주를 가진다.

각 곡은 BASE, EDIT, ALERT, DAMAGE, FINAL 레이어로 제작한다. 같은 템포·조성·마디·악기군을 공유하고 박자 경계에서 반 마디~두 마디 교차 페이드해 자연스럽게 전환한다. 즉시 필요한 경보음도 현재 곡의 조성과 음색에 맞추며 편집·감속 시 재생 속도나 음높이를 바꾸지 않는다. ALERT 3은 큰 고음 대신 낮은 맥박과 불안정한 박자를 사용하고 중요 효과음에는 짧은 음악 덕킹을 적용한다.

### 대사와 스토리 연출

짧은 대화는 캐릭터 말풍선과 하단 대사창, 이메일·인사 기록·감사 보고서는 워크북 댓글과 문서 창으로 전달한다. 핵심 사건은 맵 안의 10~20초 인게임 연출로 처리하며 경비·관리자 메시지는 조작을 막지 않는다. 긴 대화와 문서를 읽는 동안에는 세계와 타이머를 멈추고 반복 경고는 축약한다.

1차 버전은 전체 더빙 대신 역할별 전자 말소리 블립과 완전한 텍스트를 사용한다. 글자 속도, 즉시 표시, 자동·수동 넘김, 대화 기록과 블립 음량을 제공한다. 컷신은 건너뛸 수 있고 2~3줄 요약을 남긴다. 중요한 선택은 자동 확정되지 않으며 Session 6 결말 화면은 모든 게임 시간을 멈춘다. 발견한 이메일, 대화와 STORY FILE은 기록실에서 다시 열람한다.

### 저장과 이어하기

세 개의 `EMPLOYEE PROFILE`을 제공하고 Story, 함수, 감사 도장, 기록, 외형과 결말을 독립 저장한다. 접근성·음량·입력 설정은 공유한다. 영구 PROFILE, 현재 ACTIVE SESSION, 독립 REPLAY 기록과 SETTINGS를 분리한다.

Sheet 진입, 파일 패치 확정, 완료, 영구 해금, Session 결산과 결말 확정 전후에 자동 저장한다. 시트 도중 종료·새로고침 후에는 자동 복구 소비 없이 시트 시작에서 이어진다. 최근 정상 저장 세 개를 순환 백업하고 데이터 버전·무결성 검사와 마이그레이션을 지원한다. ROOT DECISION SAVE는 결말 확정 중 오류 복구용이며 같은 플레이에서 결말을 되돌리는 슬롯은 아니다.

### 카메라

이동 카메라는 중앙 데드존을 벗어날 때 부드럽게 추적하고 이동 방향 1.5셀을 더 보여준다. 기본 약 13×9셀과 세 단계 줌을 제공하며 가리는 벽·가구만 반투명 처리하고 미발견 방은 가린다. 기본 이동에는 흔들림이나 바운스를 사용하지 않는다.

편집 모드에서는 9×9 범위가 잘리지 않도록 카메라를 안정시키고 화면 밖 원격 대상과 위험은 화살표·계산선·작은 확대창으로 표시한다. 편집 중 미발견 구역 정찰은 막는다. 경보와 보스 행동은 카메라를 빼앗지 않으며 강제 이동은 안전한 컷신에서만 사용한다. 흔들림·줌·추적은 개별 설정하고 픽셀 아트는 가능한 정수 배율로 렌더링한다.

### 최종 입력 배치

키보드 이동은 WASD·Shift·E·Space, 편집은 방향키·Shift 범위·Tab 선택 방식·Q/E 대상 순환·`1~5/Z/M` 함수·Enter 실행·Space/Esc 취소를 사용한다. 마우스는 클릭·드래그 선택, 오른쪽 클릭 취소와 휠 줌을 지원한다.

게임패드 이동은 왼쪽 스틱·RT 달리기·A 상호작용·Y 편집, 편집은 방향 패드·LT 범위·Y 선택 방식·LB/RB 대상·RT 원형 함수 메뉴·A 실행·B 취소를 사용한다. 원형 메뉴에서 놓을 때는 선택만 하고 A로 따로 확정한다. 모든 입력은 재지정 가능하며 스틱 드리프트가 안내 장치를 바꾸지 않도록 임계값을 적용한다.

## 6. 주요 시스템

### 6.1 CALC

`CALC`는 함수를 실행할 때 사용하는 세션 자원이다. 무제한 편집으로 퍼즐을 무력화하지 못하도록 제한한다.

- 기본 최대치는 5이며 각 시트 시작 시 5/5로 초기화한다.
- 남은 CALC는 다음 시트로 이월하지 않고 자연 회복도 제공하지 않는다.
- 함수 기본 비용은 캠페인 전체에서 고정하고 난이도에 따라 자동 인상하지 않는다.
- 난이도는 함수 조합, 맵, 적, 제약 조건으로 높이며 복잡한 시트에는 필요한 충전 기회를 보장한다.
- 충전 노드는 시트당 한 번 CALC 2를, 중간 목표는 CALC 1을 회복한다.
- 안전 단말기의 `RECALCULATE()`는 시트당 한 번 CALC 2와 경보 1을 교환한다.
- COPY는 무료이며 실제 개체를 생성하는 PASTE에 CALC 2를 소비한다.

| 함수 | 기본 비용 | 역할 |
|---|---:|---|
| HIDE | 1 | 행 또는 열을 일시적으로 숨김 |
| COPY/PASTE | 0/2 | COPY는 무료, PASTE할 때 복제 비용 소비 |
| SORT | 2 | 범위 안의 개체 위치를 재정렬 |
| FILTER | 3 | 조건에 맞지 않는 개체를 일시적으로 제거 |
| IF | 3 | 조건과 결과를 연결한 자동화 설치 |
| UNDO | 3 | 최근 세계 상태 일부를 복원 |
| ERROR | 특수 | 강력한 오류 현상을 발생시키고 손상도 증가 |

CALC는 프린터, 서버, 계산 노드 또는 선택 보상을 통해 충전한다.

### 6.2 HIDE

행이나 열을 일정 시간 숨긴다.

- 숨겨진 영역은 내용물과 함께 활성 세계에서 제거되고 공간도 실제로 접힌다.
- 영역 안의 개체는 표시, 충돌, 외부 상호작용 대상에서 제외되며 AI와 장치 타이머가 정지한다.
- 접힌 영역 양쪽 공간이 연결되어 경비 제거, 벽 제거, 통로 연결, 이동 거리 단축에 활용할 수 있다.
- 기본 지속시간은 5초다.
- 복원 시 다른 개체와 겹치면 가장 가까운 안전 셀로 이동시킨다.
- 초기에는 플레이어가 현재 서 있는 행 또는 열을 숨길 수 없고, 후반 강화로 자기 숨기기를 해금한다.
- FINAL SHEET의 규칙 관리자와 핵심 고정 장치는 `LOCKED` 속성으로 HIDE에 저항할 수 있다.

### 6.3 COPY / PASTE

선택한 사물이나 값을 클립보드에 저장하고 다른 셀에 복제한다.

- 출입카드, 상자, 프린터, 문서 등을 복제할 수 있다.
- 복제물은 점선 테두리로 원본과 구분한다.
- CLIPBOARD의 COPY 정의는 시트 종료 또는 덮어쓰기 전까지 유지한다.
- PASTE한 DUPLICATE는 게임 시간 기준 20초 뒤 사라지며 편집 모드에서는 타이머도 20% 속도로 흐른다.
- HIDDEN 또는 `#DIV/0!` 시간 정지 중에는 수명이 멈추고 FILTERED 상태에서는 계속 감소한다.
- 만료 5초 전부터 점선 윤곽선과 남은 시간을 점멸한다.
- 특정 강화로 값만 붙여넣기, 영구 복제 또는 인물 복제를 해금할 수 있다.
- 위험한 인물 복제는 원본과 복제본이 서로를 침입자로 판단하는 상황을 만들 수 있다.

Session 1에서는 BADGE, 일반 문서, 이동식 가구와 COPYABLE 독립 장치만 복제한다. 벽, 고정 문, EXIT, OUTBOX, 원장, 충전 노드, 핵심 원본, LOCKED와 플레이어는 복제할 수 없다. 장치 복제물은 로컬 기능은 유지하지만 NETWORK_ID가 비어 인증 단말기로 쓸 수 없다. Session 2 FINAL SHEET의 `COPY ENTIRE ROW`를 해금한 뒤 일반 캐릭터를 복제할 수 있으며 복제 캐릭터는 TASK=NONE인 중립 상태로 시작한다.

### 6.4 SORT

선택한 범위 안의 인물과 사물을 속성 기준으로 재배치한다.

가능한 기준:

- 이름순
- 직급순
- 부서순
- 체력순
- 출근 시간순
- 파일 크기순

SORT는 적을 제거하지 않고 위치를 바꾸기 때문에 예측과 공간 퍼즐을 동시에 만든다.

- 시작 셀에서 Shift+방향키 또는 드래그로 직사각형 범위를 지정한다.
- 정렬 키를 가진 활성 개체 최대 12개를 대상으로 하며 HIDDEN, FILTERED, LOCKED와 플레이어는 제외한다.
- 범위의 유효 셀을 좌→우, 위→아래로 읽고 ASC/DESC 결과를 앞쪽부터 채운다.
- 같은 값은 상대 순서를 유지하고 빈 값은 마지막에 둔다.
- 실행 전 목적지를 미리 표시하며 배치가 불가능하면 CALC를 소비하지 않는다.
- 0.6초 뒤 경로 없이 동시에 재배치하고 도착 위치에서 탐지와 충돌을 다시 계산한다.

### 6.5 FILTER

조건에 맞지 않는 개체를 일정 시간 표시하지 않는다.

```text
=FILTER(OFFICE, "RANK<=STAFF")
```

FILTER는 CALC 3을 소비해 게임 시간 기준 8초 동안 유지되는 단일 동적 영역이다. 조건이 TRUE인 개체만 남기고 FALSE인 개체는 이동, AI, 장치 행동, 충돌과 탐지를 중단한다. 범위에 새로 들어오거나 속성이 바뀐 개체도 조건을 다시 검사한다. 상태 타이머는 계속 흐르지만 FILTER 영역이 HIDDEN되면 FILTER 지속시간은 정지한다. 종료 시 원래 셀 또는 가장 가까운 안전 셀에 복원한다.

### 6.6 IF

조건과 결과를 연결해 간단한 자동화를 설치한다.

조건 예시:

- 경비가 특정 셀에 진입한다.
- CCTV가 플레이어를 발견한다.
- 문이 열린다.
- 프린터가 작동한다.
- 경보 단계가 상승한다.

결과 예시:

- 문을 열거나 닫는다.
- 조명을 끈다.
- 프린터 소음을 발생시킨다.
- 스프링클러를 작동시킨다.
- 엘리베이터를 이동시킨다.

```text
=IF(GUARD.IN(C7), DOOR.OPEN)
```

IF는 CALC 3으로 설치하고 최대 2개까지 동시에 유지한다. 설치 당시 조건이 TRUE면 즉시 한 번 실행하고, FALSE면 처음 TRUE가 될 때까지 감시한 뒤 실행하고 사라진다. 기본 IF에는 ELSE가 없다. 결과는 문, 조명, 프린터, 엘리베이터, POLICY 스위치와 권한이 검증된 업무 템플릿으로 제한하며 HIDE, PASTE, SORT, FILTER, UNDO와 오류 함수는 호출할 수 없다.

### 6.7 UNDO와 버전 복원

UNDO는 CALC 3을 소비해 마지막으로 실행한 유효한 함수 명령 하나를 취소한다. 원래 함수의 CALC는 환불하지 않는다.

활용 예시:

1. SORT로 경비의 위치를 변경한다.
2. 플레이어가 경비 구역을 통과한다.
3. UNDO를 실행한다.
4. 경비는 SORT 전 셀로 돌아가지만 플레이어의 현재 위치는 유지된다.

- HIDE, PASTE, SORT, FILTER, IF 결과를 취소할 수 있다.
- 이동, 발각, 목표, 오류 함수, 문서 손상도, LOCKED, FINAL SHEET 페이즈는 취소할 수 없다.
- 이미 자연 종료된 효과와 UNDO 자체는 기록에서 제외한다.

후반부에는 서로 다른 자동 저장 버전 사이에서 물건이나 값을 복사하는 퍼즐로 확장한다.

### 6.8 오류와 문서 손상도

오류 함수는 CALC를 소비하지 않는 대신 세션 전체에 누적되는 문서 손상도를 증가시킨다. 손상도는 일반 맵에서 시간에 따라 자동 상승하지 않으며, 주로 플레이어가 오류 함수를 사용한 결과로 발생한다.

| 오류 | 효과 예시 |
|---|---|
| `#REF!` | 선택한 벽이나 방의 참조를 끊어 붕괴시킴 |
| `#DIV/0!` | 일정 범위의 시간을 정지시킴 |
| `#NAME?` | 캐릭터의 이름, 직급, 부서, 보안 등급을 10초간 제거함 |
| `#VALUE!` | 두 개체를 지정해 대상을 원본의 TYPE으로 8초간 오인식시킴. CALC 0, 손상도 +20 |

손상도가 높아지면 바닥 셀이 깜빡이고, 일부 함수 결과가 왜곡되며, 삭제된 적이 오류 개체로 돌아오거나 탈출구 좌표가 이동할 수 있다.

- 25부터 시각적 글리치가 발생한다.
- 50에서 두 이상 현상 중 하나를 선택한다.
- 75에서 이상 현상 하나를 추가 선택한다.
- 100에서 파일 충돌이 발생하고 자동 복구를 소비한 뒤 손상도 60으로 재시작한다.
- 시트 완료 보상 대신 수리를 선택하면 손상도 25와 현재 단계에 맞는 이상 현상을 제거한다.
- 후반 맵의 자동 손상 장치는 반드시 예고되고 플레이어가 정지할 수 있어야 한다.

`####`는 장착 오류 함수가 아니라 예고된 환경 오류다. 지정 열의 폭을 6초 동안 40%로 압축하되 내부 개체, 충돌과 탐지는 계속 작동한다. 손상도 이상 현상, 특수 시트와 HIDDEN SHEET의 ILLEGAL RULE에서만 사용하며 대상 열과 발생 시점을 미리 알린다.

### 일반 함수 상태 우선순위

```text
LOCKED > HIDDEN > FILTERED > SORTED > DUPLICATE
```

- HIDDEN 영역은 내부 AI, 장치, FILTER 지속시간, IF 감시를 정지한다.
- FILTERED 대상은 충돌, 탐지, 직접 선택, SORT에서 제외한다.
- SORT는 활성 상태 개체의 위치만 변경한다.
- COPY는 원본 정의와 영구 속성만 저장하고 위치, 경계, 일시 상태, LOCKED, 퀘스트 핵심 여부는 복사하지 않는다.
- IF는 다른 상태 계산 후 조건을 검사하며 기본적으로 한 번 발동한 뒤 삭제된다.

### 6.9 탐지와 경보

경비와 CCTV는 개별 탐지 게이지를 가지며 플레이어를 계속 바라봐 게이지가 100에 도달하면 완전 발각으로 판정한다. 시야를 벗어나면 게이지가 감소하고 편집 모드에서는 세계와 함께 20% 속도로 진행한다.

탐지는 단순히 플레이어가 보였는지가 아니라 `AND(IN_VIEW, POLICY_VIOLATION)`으로 계산한다. 공용 구역에서는 노출되어도 안전하며 제한 구역의 부서, 보안 등급, 운반 물품, 금지 행동과 복제 검사 조건을 위반할 때만 게이지가 오른다. 모든 정책은 입구와 HUD에서 미리 공개하고 현재 상태를 `COMPLIANT` 또는 구체적인 위반 사유로 표시한다. 신분과 타입을 바꾸는 함수는 정책 결과도 즉시 다시 계산한다.

| 단계 | 명칭 | 결과 |
|---:|---|---|
| 1 | 주의 | 주변 경비가 마지막 목격 셀을 12초간 조사 |
| 2 | 봉쇄 | 보안문을 20초간 잠그고 CCTV 회전과 경비 수색 가속 |
| 3 | 긴급 감사 | 15초간 추격. 시야를 5초간 끊으면 2단계 복귀 |

긴급 감사 중 다시 완전 발각되거나 경비에게 붙잡히면 현재 시트에 실패한다. 경보는 시트 안에서 유지하지만 다음 시트로 이월하지 않는다. 직접 경보를 올리는 함수와 장치도 해당 단계의 규칙을 발동하며 UNDO로 발각과 경보를 취소할 수 없다.

프로토타입 기준 SECURITY는 6셀·90도·2.5초, CCTV는 8셀·60도·2초, TEAM_LEADER는 4셀·100도·4초의 시야와 탐지 시간을 가진다. 시야를 벗어나거나 COMPLIANT가 되면 게이지가 초당 30 감소하고 1.5셀 이내에서는 상승 속도가 2배다. 경보 2단계는 탐지 속도 +25%, 3단계는 +50%다. 벽, 닫힌 문과 높은 가구가 몸 중심까지의 시야선을 완전히 막는다.

조명은 ON 100%, DIM 75%, OFF 50% 비율로 인간 감시자의 시야 거리와 탐지 속도를 줄인다. 일반 CCTV도 영향을 받지만 `INFRARED=TRUE` 카메라는 예외이며 붉은 렌즈로 표시한다. 어둠은 POLICY 판정을 바꾸지 않고 근접 탐지는 계속 위험하다. 조명 조작은 기본적으로 보안 사건이 아니며 시설 업무 또는 공개된 NO LIGHT CONTROL 정책으로 처리한다.

캐릭터 충돌 반경은 약 0.28셀이며 일반 NPC는 부드럽게 비켜간다. COMPLIANT 상태에서는 경비와 접촉해도 안전하다. POLICY 위반 상태로 경보 0~2단계의 경비와 접촉하면 해당 탐지 게이지가 즉시 100이 되지만 바로 실패하지는 않는다. 경보 3단계에서 SECURITY와 0.55셀 이내 접촉이 0.25초 유지될 때만 체포되어 현재 시트에 실패한다.

게임의 기본 시간대는 퇴근 직전부터 초과근무 초반이므로 정상적인 발걸음과 프린터 소리에 경비가 출동하지 않는다. 사건은 `일상음`, `업무 이벤트`, `보안 이벤트`로 분류한다. 업무 이벤트에는 직원·팀장·관리 직원이, 보안 이벤트에는 경비가 반응하며 도착 후 실제 POLICY 위반을 목격해야 탐지가 시작된다. 경보 2단계부터 달리기가 반경 3셀의 조사 사건이 되고, 3단계에서는 5셀로 증가한다. 일반 걷기는 계속 안전하다.

NPC 사건은 `TASK_ID`, `TYPE`, `ASSIGNEE_ROLE`, `PRIORITY`, `LOCATION`, `EXPIRES`, `STATUS` 필드를 가진 TASK_QUEUE 행으로 생성한다. 직원은 일반 업무와 회의, 팀장은 승인과 호출, 관리 직원은 장치 수리, 경비는 보안 사건을 처리한다. 가장 가까운 적합 직군에게 업무를 배정하고 더 높은 우선순위 사건이 현재 업무를 선점한다. 플레이어는 후반에 SORT, FILTER와 IF로 업무 순서와 배정을 조작할 수 있으며 결과 목적지를 실행 전에 확인할 수 있다.

TASK_QUEUE는 언제든 읽을 수 있지만 수정에는 구역별 DISPATCH TERMINAL 연결이 필요하다. 단말기 옆에서 2초간 연결하면 20초 동안 해당 큐의 쓰기 권한을 얻는다. 일반 단말기는 직원·시설 업무만 수정하고 보안 행은 관리자 권한이 없으면 LOCKED다. 처리 중인 업무는 직접 취소할 수 없지만 더 높은 우선순위의 장치 템플릿 업무로 선점할 수 있다.

### 6.10 소지품

플레이어는 실제 물건 하나를 드는 `HANDS`, 출입증 하나를 장착하는 `BADGE`, COPY 정의를 저장하는 `CLIPBOARD`를 사용한다. HANDS의 개체는 외부에 보이고 운반 정책 검사를 받지만 CLIPBOARD는 물리적 소지품이 아니다. BADGE는 보안문과 부서·등급 정책에 자동 사용된다. 대형 가구와 장치는 들 수 없고 세계 함수로만 이동한다.

물건을 집는 행위 자체는 위반이 아니며 감시자와 센서가 OWNER, HOME_CELL, CHECKOUT_TO, ALLOWED_ZONE, DUPLICATE를 검사한다. 자산 단말기에서 BADGE로 정상 대여할 수 있고 COPY는 대여 상태를 복사하지 않는다. `REMOVE_SENSOR=TRUE`인 원본은 HOME_CELL에서 치우면 보안 이벤트를 만들지만 어떤 필드를 검사하는지는 미리 공개한다.

## 7. 세션 진행과 성장

### 세션 시간대

한 세션은 같은 근무일의 17:50부터 18:30까지 이어진다. Sheet 1~4와 FINAL SHEET가 진행될 때마다 기준 시각이 약 10분씩 이동하고 일부 직원이 SHIFT_END에 따라 퇴근한다. 시간과 인원은 시트 안에서 실시간으로 바뀌지 않으므로 오래 고민해도 규칙이 갑자기 변하지 않는다. 이른 시트는 군중과 목격자가 많고 늦은 시트는 한산하지만 보안 인력에 노출되기 쉽다. 각 세션은 서로 다른 근무일이며 HIDDEN SHEET는 실제 시간선 밖의 복구 파일이다.

### 시트 사이 상태 계승

시트 사이에는 손상도, 이상 현상, PATCH, 자동 복구, 선택 셀, 주요 스토리 플래그와 명시된 SESSION_CARRY 물건만 유지한다. CALC, CLIPBOARD, 경보, 임시 함수, 복제물, 일반 개체 위치, TASK_QUEUE와 쓰기 권한은 초기화한다. EXIT의 OUTBOX에 목표 물건을 제출해 PASS를 계산하고 일반 운반물은 시트를 닫을 때 반환한다. SESSION_CARRY만 다음 시트의 시작 HANDS 또는 BADGE 후보로 제공하며 앞 시트의 선택이 다음 필수 해법을 막지는 않는다.

### 출근 준비

플레이어는 각 시트의 브리핑을 본 뒤 일반 함수 4개와 오류 함수 1개를 선택한다. 시트가 요구하는 핵심 함수 1~2개는 고정하고 나머지를 자유롭게 구성한다. COPY/PASTE는 한 슬롯이며 UNDO는 일반 슬롯을 차지하지 않고 항상 사용할 수 있다. 시트 진행 중에는 바꿀 수 없지만 실패 또는 재시작 후 브리핑에서는 다시 선택할 수 있다.

### 체크포인트와 자동 복구

- 세션 시작 시 자동 복구 2회를 제공하며 기본 최대치는 3회다.
- 각 시트 시작 시 체크포인트를 만들고 중간 상태는 저장하지 않는다.
- 실패 또는 수동 `RESTART SHEET` 시 자동 복구 1회를 소비해 현재 시트 시작 상태로 돌아간다.
- 완료한 이전 시트와 세션 강화는 유지하지만 실패한 시도의 CALC, 경보, 목표, 아이템, 함수 효과와 손상도 증가는 복원한다.
- 손상도 100의 파일 충돌은 예외로, 자동 복구를 소비하고 손상도 60에서 재시작한다.
- 자동 복구가 없을 때 실패하면 세션이 끝나며 다음 도전은 Sheet 1부터 시작한다.
- 정상 종료 후 이어하기는 자동 복구를 소비하지 않지만 해당 시트 시작점에서 재개한다.

### 제한시간

일반 시트에는 실패를 유발하는 전체 제한시간을 두지 않는다. 경과 시간은 개인 기록으로만 저장하며 보상과 해금에는 영향을 주지 않는다. 시간 압박이 주제인 특수 시트에만 브리핑으로 예고한 제한시간을 적용하며, 편집 모드에서는 세계와 함께 20% 속도로 진행한다. 시간 초과는 일반 시트 실패로 처리한다.

### 시트 완료 평가표

- 필수 목표와 EXIT 도달을 `AND` 수식으로 계산해 `PASS` 또는 `FAIL`을 표시한다.
- PASS면 선택 목표와 관계없이 다음 시트와 핵심 기능을 해금한다.
- 각 시트에는 시작부터 공개되는 고유 선택 목표 3개가 있다.
- 선택 목표는 하나의 정답 플레이를 강요하지 않고 원본 보존, 타입 오인식, 복제 우회처럼 시트의 독특한 함수 조합을 유도한다.
- 세 조건은 한 번에 모두 달성할 수 있어야 하며 달성한 셀은 영구적으로 저장한다.
- 경과 시간은 결과표에 표시하지만 평가 수식에는 포함하지 않는다.

### 선택 셀 누적 보상

한 세션의 선택 셀 15개는 소비되지 않는 `AUDIT STAMP`로 영구 기록한다.

| 누적 도장 | 보상 |
|---:|---|
| 5 | 비밀 이메일·추가 이야기와 사무실 장식 |
| 10 | 캐릭터 액세서리와 함수 시각 효과 |
| 12 | 독립 보너스 퍼즐 `HIDDEN SHEET` |
| 15 | 황금 워크북 탭과 세션 마스터 칭호 |

도장은 반복 획득하거나 소비하지 않으며 필수 함수와 메인 진행은 선택 셀 보상으로 잠그지 않는다.

### HIDDEN SHEET

- 세션별 감사 도장 12개로 열리는 8~12분 분량의 독립 고난도 퍼즐이다.
- 첫 도전은 지정된 함수 슬롯과 CALC로 진행하며 세션 규칙을 종합한다.
- 각 시트에는 시작 전에 공개되는 고유 `ILLEGAL RULE` 하나가 있다.
- 강제 제한시간과 선택 목표는 없고 실패해도 본편 자동 복구를 소비하지 않는다.
- 내부 경보와 손상도는 본편에 영향을 주지 않으며 무제한으로 재시작할 수 있다.
- 첫 PASS 후 자유 함수 조합을 사용하는 `SANDBOX RECALC`를 해금한다.
- 완료 보상은 추가 이야기와 외형 요소로 제한한다.

### 시트 완료 보상

Sheet 1~4를 완료하면 `FORMULA PATCH`, `SYSTEM PATCH`, `RISK PATCH`에서 하나씩 제시된 세 가지 강화 중 하나를 선택한다. PATCH는 세션 동안 최대 네 개가 누적되고 다음 세션에는 초기화된다. 필수 해법에는 필요하지 않으며 기본 함수 비용은 명시된 예외 외에는 바꾸지 않는다. 손상도 수리가 필요하면 해당 시트의 PATCH 대신 `REPAIR WORKBOOK`을 선택한다.

- 수식 흔적 삭제: HIDE가 끝날 때 주변 감시자의 탐지 게이지 초기화
- 값만 붙여넣기: 제한된 조건에서 복제물의 DUPLICATE 검사를 지연
- 클립보드 확장: 두 개의 대상을 저장
- 자동 저장 확장: 최대치 안에서 자동 복구 1회 추가
- 휘발성 붙여넣기: PASTE 비용 1 감소, 복제물 지속시간 단축
- 책임 전가: 첫 보안 조사 업무를 가까운 복제물 위치로 변경

강화는 현재 세션 동안 유지된다.

### 매크로

여러 동작을 묶은 강력한 일회성 기능이다. Session 3에서 영구 해금하고 세션 브리핑에서 하나를 전용 M 슬롯에 장착한다. CALC와 손상도를 소비하지 않지만 세션 전체에서 한 번만 사용할 수 있다. 실행 전 모든 단계와 부작용을 미리 표시하며 조건이 유효하지 않으면 횟수를 소비하지 않는다. 전체 MACRO는 UNDO 기록 하나지만 UNDO해도 사용 횟수와 경보는 복구되지 않는다.

```text
=MACRO("퇴근")
1. 모든 조명 OFF
2. 경비를 출구 반대편으로 SORT
3. 플레이어가 있는 행 HIDE
4. 5초 뒤 원상 복구
```

회사식 매크로 이름을 게임의 유머로 활용한다.

- 칼퇴
- 책임 전가
- 회의 소집
- 긴급 점검
- 연차 사용
- 담당자 부재
- 메일 전체 회신

캠페인에서는 제작된 MACRO만 사용하고 HIDDEN SHEET의 SANDBOX RECALC에서만 최대 3단계 사용자 MACRO를 만들 수 있다.

Session 3에서 최초 세 개를 해금한다. `회의 소집`은 OPERATIONS 직원과 팀장을 회의실로 모으고 회의록 업무 2개를 남긴다. `담당자 부재`는 FACILITIES 업무와 자동 복구를 10초 멈춘 뒤 경보를 1 올린다. `긴급 점검`은 조명을 10초 끄고 일반 문을 5초 열며 CCTV 회전을 멈춘 뒤 사용 위치에 우선순위 100 SECURITY 업무를 만든다.

## 8. 실패 및 복구

세션 시작 시 자동 복구 파일을 기본 2개 제공한다. PATCH 등으로 회복하더라도 최대 3개까지만 보유한다.

```text
AutoRecovery_01
AutoRecovery_02
```

실패 시 현재 시트를 처음부터 다시 시작하고 복구 파일 하나를 소비한다. 현재까지 얻은 세션 강화는 유지하고 일반 실패에서 발생한 손상도는 시트 진입 시점으로 복원한다. 손상도 100으로 인한 파일 충돌만 예외로 손상도 60에서 재시작한다.

복구 파일을 모두 잃으면 해당 세션이 종료된다. 긴장감을 유지하면서도 20분의 진행을 한 번의 실수로 전부 잃는 상황은 피한다.

## 9. 캠페인 세션 구성

### 함수 영구 해금

| 세션 | 해금 |
|---|---|
| 1 | HIDE, COPY/PASTE |
| 2 | SORT, FILTER |
| 3 | IF, MACRO |
| 4 | UNDO, 자기 행·열 HIDE |
| 5 | `#NAME?`, `#DIV/0!`, `#VALUE!`, `#REF!` |
| 6 | 신규 함수 없이 전체 조합 |

새 함수는 튜토리얼 시트를 PASS하면 영구 해금한다. 완료한 시트는 당시 기능으로 AUDIT STAMP를 얻는 `STORY VERSION`과 현재 보유한 모든 함수로 자유롭게 푸는 `RECALC VERSION`을 제공한다. RECALC 기록은 정규 선택 셀과 분리한다.

PATCH 후보는 무작위가 아니라 각 시트 이후 남은 퍼즐을 기준으로 수제 제작한다. 사용자 화면에서는 `파일 패치`와 `이번 세션에만 적용되는 패시브 업그레이드`로 설명한다. Sheet 1~4 완료마다 FORMULA, SYSTEM, RISK 한 장씩을 제시하고 손상도가 있으면 REPAIR WORKBOOK을 네 번째로 추가한다. 다음 시트 진입 전까지 선택을 바꿀 수 있으며 진입 뒤 확정한다. STORY VERSION은 당시 선택을 기록하고 RECALC VERSION은 발견한 PATCH를 자유롭게 시험한다.

파일 패치는 홈의 게임 선택 시트와 분리된 전체 화면 `PATCH_NOTES.xlsx`에서 고른다. 왼쪽 누적 패치, 중앙 고정 후보와 REPAIR, 오른쪽 다음 시트 미니맵·영향 대상을 배치한다. 선택 수치와 우회로를 미리 본 뒤 `다음 Sheet 열기`를 누를 때 확정한다.

Session 1 Sheet 1 PATCH는 `접힘 유지`(HIDE 7초), `이중 클립보드`(정의 2개), `빠른 임시 숨김`(시트 첫 HIDE 무료, 모든 HIDE 3초) 중 하나다.

Session 1 Sheet 2 PATCH는 `장기 복제 캐시`(복제 30초), `즉시 장착`(PASTE 대상을 BADGE로 직접 교체), `저해상도 복제`(PASTE 비용 1, 복제 10초) 중 하나다.

Session 1 Sheet 3 PATCH는 `중복 판정 지연`(DUPLICATE 5초 유예), `세션 클립보드`(정의 하나를 다음 시트로 계승), `메아리 사본`(인접 ECHO_COPY 6초) 중 하나다.

Session 1 Sheet 4 PATCH는 `숨김 보호`(첫 강제 UNHIDE 무효), `빠른 결재`(FINAL 제출 1초), `과잉 증빙`(복제 점수 +24, 관리자 복구 3초 단축) 중 하나다.

Session 2 Sheet 1 파일 패치는 `보조 정렬 키`(SORT 두 번째 키), `확장 데이터 범위`(SORT/FILTER 16개), `긴급 재배치`(SORT 비용 1, SECURITY 검토 업무) 중 하나다.

Session 2 Sheet 2 파일 패치는 `복합 필터`(조건 두 개 AND/OR), `정책 스캐너`(대상별 정책 판독), `빠른 필터`(비용 2, 지속 5초) 중 하나다.

Session 2 Sheet 3 파일 패치는 `역조건 필터`(TRUE/FALSE 유지 선택), `연결 유지`(LINKED/Dispatch 30초), `강제 격리`(FILTER 15초, 종료 시 SECURITY 검토) 중 하나다.

Session 2 Sheet 4 파일 패치는 `감사 봉인`(첫 SHOW_ALL/정렬 복구 무효), `검증 캐시`(유효 표본 6초), `간이 감사`(표본 3행, Chief 주기 7초) 중 하나다.

Session 3 Sheet 1 파일 패치는 `복합 조건식`(IF 조건 두 개), `수식 슬롯 확장`(활성 IF 3개), `임시 수식`(비용 2, FALSE 10초 만료) 중 하나다.

Session 3 Sheet 2 파일 패치는 `예약 실행`(IF 결과 0~5초 지연), `조건 포커스`(발동 순간 1초 감속), `무선 수식`(8셀 원격 결과, 경보 +1) 중 하나다.

Session 3 Sheet 3 파일 패치는 `조건 전달`(IF TRUE 기록 6초), `듀얼 매크로`(2개 장착·총 1회), `매크로 재실행`(2회, 두 번째 경보 +1) 중 하나다.

Session 3 Sheet 4 파일 패치는 `종료 잠금`(첫 RECONNECT 무효), `연결 캐시`(첫 CLEAR_LINKS 무효), `고속 업무 처리`(업무 1초, Director 주기 9초) 중 하나다.

Session 4 Sheet 1 파일 패치는 `선택 실행 취소`(최근 거래 2개 중 선택), `변경 추적 패널`(거래와 감사 정보), `긴급 실행 취소`(UNDO 비용 2, 3초 AUDIT_TARGET) 중 하나다.

Session 4 Sheet 2 파일 패치는 `새 타임스탬프`(새 감사 대상 6초 초기화), `버전 오버레이`(과거 상태 상시 표시), `강제 감사`(즉시 복구, 경보 +1) 중 하나다.

Session 4 Sheet 3 파일 패치는 `가변 자기 숨김`(3·5·7초), `숨김 관찰 모드`(숨김 중 읽기 전용 검사), `인접 셀 복원`(첫 자기 HIDE 인접 복원, 경보 +1) 중 하나다.

Session 4 Sheet 4 파일 패치는 `수식 자동 정리`(LOCKED 외부 IF 흔적 제거), `감사 예고 연장`(FINAL 예고 4초), `고속 비교`(PASTE 1, 감사 빔 2회) 중 하나다.
